# Typst语法简记

学习自typst官方文档：[用 Typst 写作——Typst 文档 --- Writing in Typst – Typst Documentation](https://typst.app/docs/tutorial/writing-in-typst/)


| 符号            | 作用                                                                             | 描述                                                                                                                   |
| ------------- | ------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------- |
| =             | 标题                                                                             | 几个=就是几级标题                                                                                                            |
| _（下划线）        | 斜体                                                                             | 同md                                                                                                                  |
| 空行            | 添加新段落                                                                          | 常识                                                                                                                   |
| +             | 编号列表，用数字                                                                       | ![[Pasted image 20260129145631.png]]                                                                                 |
| -             | 符号列表，用小圆点                                                                      | 在列表中缩进表示嵌套列表![[Pasted image 20260129145923.png]]                                                                     |
| #             | 调用函数                                                                           |                                                                                                                      |
| image函数       | 插入图片，图片和主文档同级，默认左对齐                                                            | ![[Pasted image 20260129150235.png]]                                                                                 |
|               | 传参改变图像大小                                                                       | #image("glacier.jpg",width:70%)<br>#image("glacier.jpg",width:1cm)                                                   |
| figure函数      | 图形函数，内可嵌套使用image函数，用方括号[]构造内容块来自定义图片标题                                         | ![[Pasted image 20260129150911.png]]                                                                                 |
| <尖括号>         | 给图表贴标签                                                                         | ![[Pasted image 20260129151118.png]]                                                                                 |
| @             | 引用贴了标签的图表                                                                      |                                                                                                                      |
| #bibliography | 引用参考文献                                                                         | ![[Pasted image 20260129151629.png]]                                                                                 |
| $             | 写数学表达式                                                                         | 紧贴$符表示行内公式， $符开头和结尾各插入一个空格表示单独成行，多个字母被解释为符号、变量或函数名称。要暗示单个字母之间的乘法，可以在字母之间加空格。<br>![[Pasted image 20260129151833.png]] |
|               | 用引号包住表示多词组成的变量                                                                 | ![[Pasted image 20260129152221.png]]                                                                                 |
|               | _表下标，^表上标，（）圆括号包含多个内容                                                          | sum上下标指定求和范围，/直接表示分数<br>![[Pasted image 20260129152310.png]]                                                         |
|               | vec函数表示列向量，在数学模式下不需要#调用                                                        | ![[Pasted image 20260129152735.png]]                                                                                 |
|               | 更多数学调用函数参考[Math – Typst Documentation](https://typst.app/docs/reference/math/) |                                                                                                                      |
|               |                                                                                |                                                                                                                      |
