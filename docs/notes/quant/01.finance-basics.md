# 金融市场基础知识

## 1. 金融市场概览

金融市场是资金供应者和资金需求者进行交易的场所。对于量化交易者来说，理解市场的基本运作机制是构建任何策略的基石。

### 主要资产类别
*   **股票 (Stocks/Equities)**: 代表公司的所有权份额。
*   **债券 (Bonds/Fixed Income)**: 借贷契约，通常支付固定利息。
*   **期货 (Futures)**: 约定在未来特定时间以特定价格买卖资产的合约。广泛用于对冲和投机。
*   **期权 (Options)**: 赋予持有者在未来特定时间以特定价格买卖资产的权利（而非义务）。
*   **外汇 (Forex)**: 不同国家货币之间的兑换交易。
*   **加密货币 (Cryptocurrency)**: 基于区块链技术的数字资产。

## 2. 交易微观结构 (Market Microstructure)

这是理解高频交易最核心的部分，研究的是交易机制如何影响价格形成。

### 订单簿 (Order Book)
大多数现代交易所使用**限价订单簿 (LOB)** 机制。
*   **买单 (Bid)**: 愿意买入最高的价格。
*   **卖单 (Ask/Offer)**: 愿意卖出最低的价格。
*   **价差 (Spread)**: 最低卖出价 (Ask 1) 与最高买入价 (Bid 1) 之间的差额。流动性越好，价差越小。
*   **深度 (Depth)**: 不同价格水平上的挂单数量。

### 订单类型
*   **市价单 (Market Order)**: 立即以当前市场最优价格成交。吃掉流动性 (Taker)，通常需要支付较高的手续费，且面临滑点风险。
*   **限价单 (Limit Order)**: 指定价格买入或卖出。提供流动性 (Maker)，通常手续费较低甚至有返佣，但不保证成交。
*   **止损单 (Stop Order)**: 价格触发特定水平后转为市价单。

## 3. 常见的交易概念

*   **多头 (Long)**: 买入资产，期望价格上涨。
*   **空头 (Short)**: 借入资产卖出，期望价格下跌后再买回归还。
*   **杠杆 (Leverage)**: 使用借来的资金进行交易，放大收益同时也放大风险。
*   **滑点 (Slippage)**: 预期成交价与实际成交价之间的差异，通常由市场波动或流动性不足引起。
*   **流动性 (Liquidity)**: 资产在不剧烈影响价格的情况下迅速买卖的能力。

## 4. 市场参与者

*   **散户 (Retail Investors)**: 个人投资者，资金量小，通常是价格接受者。
*   **机构投资者 (Institutional Investors)**: 基金、养老金、保险公司等，资金量大，交易可能影响市场价格。
*   **做市商 (Market Makers)**: 专门提供流动性的机构，同时报出买价和卖价，赚取价差。
*   **高频交易商 (HFT Firms)**: 利用极速技术进行大量短线交易的机构。
