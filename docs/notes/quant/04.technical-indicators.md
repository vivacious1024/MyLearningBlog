# 金融量化笔记：技术指标详解 (MACD与RSI)

在金融市场的传统量化策略中，技术指标扮演着重要角色。它们基于历史价格和成交量数据，通过数学公式计算得出，用以辅助判断市场趋势和买卖时机。本文主要介绍两个最常用的经典指标：MACD 和 RSI。

## 1. MACD (Moving Average Convergence Divergence)
**中文名称**：指数平滑异同移动平均线  
**发明者**：Gerald Appel (1970年代)

MACD 被称为“指标之王”，它利用收盘价的短期（常用12日）指数平滑移动平均线与长期（常用26日）指数平滑移动平均线之间的聚合与分离状况，对买进、卖出时机作出研判。

### 1.1 核心组成
MACD指标由三部分组成：
1.  **DIF (差离值)**：短期EMA（指数移动平均）与长期EMA的差。
    *   *公式*：$DIF = EMA(12) - EMA(26)$
    *   *含义*：代表股价短期趋势与长期趋势的偏离程度。
2.  **DEA (讯号线)**：DIF的M日（常用9日）指数平滑移动平均线。
    *   *公式*：$DEA = EMA(DIF, 9)$
    *   *含义*：对DIF进行平滑，过滤掉部分噪音，作为DIF的信号线。
3.  **MACD柱 (红绿柱)**：DIF与DEA差值的2倍。
    *   *公式*：$Histogram = 2 \times (DIF - DEA)$
    *   *含义*：直观展示多空力量的强弱。红柱代表多头主导，绿柱代表空头主导。

### 1.2 常用交易信号
*   **金叉 (Golden Cross)**：DIF线上穿DEA线，且位置在0轴下方或附近，通常视为**买入**信号。
*   **死叉 (Death Cross)**：DIF线下穿DEA线，通常视为**卖出**信号。
*   **顶背离**：股价创出新高，但MACD红柱或DIF线没有创新高（反而走低），预示**下跌**风险。
*   **底背离**：股价创出新低，但MACD绿柱或DIF线没有创新低（反而走高），预示**反弹**机会。

### 1.3 优缺点
*   **优点**：主要用于判断中长期趋势，稳定性好，能有效过滤短期波动噪音。
*   **缺点**：具有滞后性，在盘整震荡市中容易频繁发出错误信号（左右挨耳光）。

## 2. RSI (Relative Strength Index)
**中文名称**：相对强弱指标  
**发明者**：Welles Wilder (1978年)

RSI 是一种动量指标，通过比较一段时期内（常用14日）收盘价涨幅和跌幅的平均值，来评估市场的买卖力量强弱，从而预测价格的未来走势。

### 2.1 核心原理
RSI 的数值范围在 **0 到 100** 之间。它的核心思想是：在强势市场中，多头力量强于空头，价格上涨幅度较大；反之亦然。

*   *简化公式概念*：
    $$RSI = 100 - \frac{100}{1 + RS}$$
    其中 $RS = \frac{\text{N日内平均涨幅}}{\text{N日内平均跌幅}}$

### 2.2 常用交易信号
RSI 主要用于判断市场的**超买** (Overbought) 和 **超卖** (Oversold) 状态：

1.  **超买区 (**RSI > 70/80**)**：
    *   当 RSI 超过 70（激进市场看 80）时，表示市场处于“超买”状态，买方力量可能透支，价格面临回调或下跌风险，是**卖出**警示。
2.  **超卖区 (**RSI < 30/20**)**：
    *   当 RSI 低于 30（激进市场看 20）时，表示市场处于“超卖”状态，卖方力量可能衰竭，价格面临反弹机会，是**买入**警示。
3.  **中轴线 (RSI = 50)**：
    *   50 是多空分界线。RSI > 50 表示多头占优，RSI < 50 表示空头占优。
4.  **背离信号**：
    *   与 MACD 类似，当价格创新高而 RSI 未创新高（顶背离），或价格创新低而 RSI 未创新低（底背离），往往是强烈的反转信号。

### 2.3 优缺点
*   **优点**：反应灵敏，适合短线操作，能较好地识别市场的极端情绪（超买/超卖）。
*   **缺点**：在单边大牛市或大熊市中，RSI 会出现“钝化”现象（例如长期停留在超买区而价格继续上涨），此时仅凭超买信号卖出可能会踏空。

---

## 总结
*   **MACD** 更侧重于**趋势**的判断，适合中长线，稳健但滞后。
*   **RSI** 更侧重于**动量**和**情绪**的判断，适合短线，灵敏但容易产生假信号。
*   **量化策略应用**：在构建策略时，通常不会单用一个指标，而是将两者结合。例如，用 MACD 确定大趋势方向，配合 RSI 寻找具体的入场点，或者结合其他数据（如成交量、基本面）来过滤信号。
